# הצוות שלי: אפליקציית נוכחות למילואים

PWA בעברית לניהול נוכחות ותנועות של צוות. אין צורך בשרת: הנתונים נשמרים במכשיר (localStorage), והאפליקציה עובדת גם בלי אינטרנט.

## העלאה בחינם

### אפשרות א': Netlify Drop (הכי מהיר, בלי חשבון GitHub)
1. נכנסים ל-https://app.netlify.com/drop ומתחברים (חינם).
2. גוררים את **כל התיקייה** `אפליקציה למילואים` לחלון.
3. מקבלים כתובת כמו `https://xxxx.netlify.app`. אפשר לשנות אותה ב-Site settings → Change site name.

### אפשרות ב': GitHub Pages
1. יוצרים מאגר (repository) חדש ציבורי ב-github.com, למשל `miluim`.
2. Add file → Upload files → גוררים את כל הקבצים והתיקיות (index.html, sw.js, manifest.webmanifest, css, js, icons) → Commit.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save.
4. אחרי דקה-שתיים האתר זמין בכתובת `https://<שם-משתמש>.github.io/miluim/`.

## התקנה בטלפון
- **אייפון:** פותחים את הכתובת ב-Safari → כפתור שיתוף → "הוסף למסך הבית".
- **אנדרואיד:** פותחים ב-Chrome → תפריט ⋮ → "התקנת אפליקציה".

## עדכון גרסה
אחרי שינוי בקבצים מעלים את המספר ב-`sw.js` (`miluim-v1` → `miluim-v2`) ומעלים מחדש. כך הטלפונים יקבלו את הגרסה החדשה.

## חשוב
- הנתונים שמורים רק בטלפון שבו הוזנו. אם תמחק את האפליקציה או תנקה את נתוני הדפדפן, הם יימחקו. כדאי לייצא גיבוי JSON מדי פעם (הגדרות → גיבוי).
- הכתובת הציבורית מכילה רק את הקוד ואת נתוני הפתיחה (שמות הצוות, ב-`js/seed.js`). אם לא רוצים שהשמות יופיעו בקוד ציבורי, אפשר למחוק אותם מהקובץ לפני ההעלאה ולהזין אותם באפליקציה.
